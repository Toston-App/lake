## Dependency notes

  `compute_portfolio_totals` / `portfolio_today` from
  `app/services/portfolio_snapshot.py`.
- After 001 is deployed, history accumulates one point per day. The chart is
  only as long as the time since deployment, because there is no backfill.

## Other direction findings (not planned yet)

From the same session. Ask for a plan if you want any of them:

- Realized gains and dividend income: sells don't store a realized P&L, and dividends do nothing (`investment_transactions.py:794-797`).
- Manual / fixed-income assets (CETES, bonds, funds): normal users can't create them, and there is no manual price entry.
- WhatsApp investment logging: large, and best done after manual assets.

## Findings considered and rejected

- Broker CSV import (GBM, Bitso, IBKR): each broker needs its own parser to maintain, which costs more than it's worth before users ask for it.
- Rebuilding performance history from transactions + Yahoo historical prices instead of snapshots: much heavier and depends on Yahoo. It stays an optional later backfill on top of plan 001.
